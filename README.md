# NBA Draft Analytics & Player Projection

A work-in-progress Python project exploring the use of statistical analysis and machine learning to evaluate basketball players and project their potential NBA success.

The goal is to develop a data-driven player evaluation system that identifies relationships between player characteristics, historical performance, and long-term NBA success. By combining basketball statistics, player attributes, and machine learning, the project aims to provide an alternative perspective on player evaluation and prospect analysis.

## Current Development

The project currently focuses on several areas:

- **Data Collection:** Gathering historical NBA player statistics, biographical information, physical attributes, and performance indicators.
- **Data Processing:** Cleaning, organizing, and transforming collected data into structured datasets.
- **Feature Engineering:** Developing statistical features and a composite success metric based on historical NBA performance and achievements.
- **Feature Selection:** Exploring the predictive value of different player attributes and statistical indicators.
- **Machine Learning:** Developing an XGBoost regression model to estimate player success scores.
- **Prospect Evaluation:** Applying trained models to prospect datasets to generate comparative player projections.

Additional player evaluation methods and alternative data sources are also being explored.

## Technology Stack

- **Python** for application development and data processing.
- **Pandas & NumPy** for data manipulation and statistical analysis.
- **Scikit-learn** for preprocessing, feature selection, and model evaluation.
- **XGBoost** for machine learning and regression.
- **BeautifulSoup & Selenium** for web scraping and data collection.
- **SQLite** for structured data storage.

## Project Status


This project is under active development. Data collection, feature engineering, model development, and player evaluation methodologies are still being refined.

Current areas of exploration include:

- Improving the quality and breadth of historical player data.
- Refining the composite player success metric.
- Identifying meaningful predictors of professional basketball success.
- Evaluating model performance and predictive reliability.
- Expanding prospect coverage and exploring additional player evaluation approaches.

The long-term objective is to develop a flexible analytical framework for basketball talent evaluation and NBA prospect projection.
